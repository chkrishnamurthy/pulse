Everything else that was fixed

Medium and Low fixes

Screens, sign-in and widgets (Claude 1)

  • Back button now returns to Today, then exits. It used to cycle through every tab visited.
  • Midnight: screens switch to the new day without a restart. Covered by a test with a fake clock.
  • Status bar stays readable when you force Light or Dark mode.
  • Settings: "Connect Google account" button, a plain-English connection check (for example "account not linked"), a first-sync progress card.
  • Miles setting now applies on Today and Trends too.
  • Accessibility: labels on the reorder buttons; the insight dot is green for good news.
  • Lint: language-change bugs, a widget layout split for Android 12+, backup turned off on Android 9–11 too.
  • 27 new UI tests for reports, formatting, mappers, the smart widget and day rollover.

Data and sync (Claude 2)

  • Deleted sessions: sleep or workouts removed at Google are now removed in the app too.
  • Heart-rate refresh is now one database transaction (no half-empty day).
  • Pull-to-refresh no longer waits minutes behind the first history download.
  • Widgets clear themselves after "Delete data" or sign-out.
  • Rate-limit waits are capped, so a bad server reply can't stall sync for hours.
  • Sign-in errors tell "no internet" from "sign in again" reliably.
  • Release build shrinks resources as well as code.
